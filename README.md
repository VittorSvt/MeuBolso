# MeuBolso

Sistema web para controle de gastos pessoais, desenvolvido como projeto final da disciplina.

## Sobre o projeto

O MeuBolso tem como objetivo ajudar o usuário a organizar suas finanças pessoais, permitindo cadastrar receitas e despesas e acompanhar os gastos durante o mês.

A ideia é criar uma aplicação simples, onde cada usuário possa visualizar suas movimentações financeiras e entender melhor para onde seu dinheiro está indo.

## Funcionalidades previstas

- Cadastro e login de usuários
- Registro de receitas e despesas
- Organização de despesas por categorias
- Edição e exclusão de movimentações
- Resumo financeiro mensal
- Visualização do saldo disponível

## Tecnologias

- PHP
- HTML
- CSS
- JavaScript
- MySQL/MariaDB
- Docker

## Desenvolvimento

O projeto está em desenvolvimento. As funcionalidades serão implementadas gradualmente, começando pela estrutura da aplicação e depois pela API, banco de dados e interface.
